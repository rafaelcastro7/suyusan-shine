### 1. Start Dev Server
```bash
npm run dev
# Opens: http://localhost:8080/
```

### 2. Use Professional Skills

#### Add a New Feature
```bash
/code-factory
I need to add a service booking feature to the contact form.
```

#### Create UI Component
```bash
/claude-design
Create a service booking modal with date picker and time selection.
Theme: Tailwind + shadcn/ui, color: brand green (#00d9ff)
```

#### Apply Design System
```bash
/premium-vibe-styler
Generate CSS for premium service cards with glassmorphism and glow effects.
Base: deep_dark, accent: #00d9ff
```

#### Deploy to Production
```bash
/full-stack-deployment-pipeline
Set up Docker deployment for Suyusan with PostgreSQL and monitoring.
```

### 3. Commit & Sync
```bash
git add .
git commit -m "feat: add service booking feature"
git push origin main
# Lovable automatically syncs
```
